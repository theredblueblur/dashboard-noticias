Datos leídos de noticias.json, publicado junto con esta página. El botón Refresh solo vuelve a leer ese archivo; para recopilar noticias nuevas usa el workflow de GitHub Actions. Los indicadores se calculan únicamente con las noticias del archivo; este tablero no muestra cotizaciones.

Cómo traer noticias nuevas

Este tablero solo lee el archivo noticias.json. La recopilación de noticias la hace el workflow del repositorio:

  1. Entra a GitHub y abre el repositorio del tablero.
  2. Ve a la pestaña Actions.
  3. Selecciona Actualizar noticias y publicar dashboard.
  4. Presiona Run workflow y confirma con el segundo Run workflow.
  5. Cuando el workflow termine y la página se vuelva a publicar, presiona Refresh aquí.

Refresh no ejecuta GitHub Actions ni descarga RSS: únicamente vuelve a leer el archivo publicado.
